Pages
/            Overview. Data-flow and store diagrams on the architecture section.
/monitor     Camera wall and alert rail. Tile pictures are placeholders. Labels and alerts are real incidents.
/playback    Search by date, camera, event. Player is the incident timeline, not a video file.
/edge        Live edge. Webcam or an uploaded file. File uploads skip the score gate and use Aisle 4.
/investigate Upload or record a clip (max 15 MB). This page and the incident it opens can play that local file.
/incident    Verdict, receipt, confirm or dismiss. Video only if this tab still holds the upload blob.
/rules       Plain-English rule compiled by Gemini.
/about       How the two tiers work.
/setup       Cloud dependency check. Not in the nav.

Clips
Drop files later in web/public/clips/ (see the README there).
Names: lane-1.mp4, lane-2.mp4, aisle-4.mp4, aisle-2.mp4.
Git ignores mp4, webm, and mov. Monitor and Playback do not play them yet.

What is stored
Firestore (Cloud Run) or memory (local): cameras, zones, skus, transactions, incidents, rules, cache, counters, meta/seed.
The cache stores an incident id for a clip hash. It does not store the video.
